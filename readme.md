# 央视视频下载工具

这是一个用于获取央视视频下载链接的浏览器脚本工具。该脚本可以在访问央视视频页面时自动提取视频PID，并生成可用于下载的m3u8格式链接。

## 功能特点

- 自动从央视视频页面提取视频PID
- 支持多种URL格式的解析
- 生成多个CDN域名的视频链接
- 简单易用的界面操作
- 一键复制下载链接

## 安装方法

### 方法一：使用Tampermonkey（推荐）

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击扩展图标，选择"添加新脚本"
3. 复制 `cctv.js` 文件的全部内容，粘贴到编辑框中
4. 点击保存按钮

### 方法二：直接在控制台运行

1. 在央视视频页面，按 F12 打开开发者工具
2. 切换到控制台（Console）标签页
3. 复制 `cctv.js` 文件的全部内容，粘贴到控制台中
4. 按回车执行

## 使用方法

1. 打开央视视频网页 (如 https://tv.cctv.com/)
2. 等待脚本自动识别视频内容（可能需要几秒钟）
3. 页面右上角会出现一个蓝色的"获取下载链接"按钮
4. 点击按钮，脚本会自动生成视频链接
5. 链接生成成功后会自动复制到剪贴板，并显示成功提示

## 支持的视频页面

- 央视网 (tv.cctv.com) 的各类视频页面
- 包含VIDE开头的视频ID的页面
- 包含pid参数的视频页面

## 技术说明

### URL构建

脚本会自动尝试以下几种CDN域名格式：

- newcntv.qcloudcdn.com
- cntv.qcloudcdn.com
- hls.cntv.lxdns.com
- dhlswswx01.v.cntv.cn

URL路径格式为：
`/asp/hls/450/0303000a/3/default/{视频PID}/450.m3u8`

## 常见问题

### 为什么点击按钮后没有获取到链接？

- 可能页面中没有找到视频PID信息
- 尝试刷新页面后再次点击
- 确认当前页面是有效的视频播放页面

### 生成的链接无法播放或下载？

- 央视的视频链接可能有访问限制
- 尝试使用不同的下载工具
- 确保网络环境可以访问央视的CDN服务
